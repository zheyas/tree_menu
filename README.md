
# Django Tree Menu

**Tree Menu** — Django-приложение для отображения древовидных меню с поддержкой вложенности, активных пунктов и нескольких меню на одной странице.  
Выполнено по условиям типового тестового задания для backend разработчика.

## Основные возможности

- Хранение структуры меню в базе данных (Menu, MenuItem)
- Редактирование меню и пунктов через стандартную админку Django
- Отрисовка любого меню через template tag:  
    ```{% draw_menu 'menu_name' %}```

- Определение активного пункта меню по текущему URL
- Развёрнуто всё над активным пунктом и первый уровень под ним
- Поддержка нескольких меню на одной странице  
- На отрисовку каждого меню ровно **один** запрос к БД
- Поддержка URL как явного (URL), так и через named url (reverse)
- Минимум зависимостей: только Django

## Как установить

1. Клонируйте репозиторий:
```
git clone https://github.com/zheyas/tree_menu.git
```

2. Добавьте приложение в ваш `INSTALLED_APPS`:
```
INSTALLED_APPS = [
        ...,
        'tree_menu',
    ]
```
3. Выполните миграции:
```
python manage.py makemigrations
python manage.py migrate 
```
4. (Опционально) Заполните меню тестовыми данными:
```
python manage.py fill_menus
``` 


5. Зарегистрируйте меню и пункты меню через Django admin.

Предварительно необходимо создать суперпользователя с помощью
```
python manage.py createsuperuser
```

## Использование
Можно вставить тег меню в нужном шаблоне:
```
{% load tree_menu_tags %}
{% draw_menu 'main_menu' %}
```
main_menu или другой — это имя вашего меню из базы.

## Логика раскрытия

- Определяется активный пункт меню на основе request.path.
- Все предки активного пункта развёрнуты (видна вся цепочка "до корня").
- Первый уровень вложенности под активным пунктом также развёрнут.
- Остальные ветки меню свернуты.


## Модели

- Menu: название меню
- MenuItem: пункт меню, поддерживает древовидную структуру (ссылается на parent), url/named_url


## Пример админки

- Добавьте через admin Menu (например, main_menu, details_menu, help_menu)
- К каждому Menu добавьте пункты MenuItem. Для вложенности используйте поле "Parent".

## Проверка

- Зайдите на любую страницу — меню должно автоматически показывать активную ветку согласно текущему URL.
- Для добавления пунктов меню используйте админку.
